# Binance Square Auto-Poster

بوت بينشر تلقائيًا على Binance Square كل ساعة تقريبًا، بمحتوى بيكتبه خط
إنتاج من نماذج ذكاء اصطناعي مجانية، مبني على بيانات حقيقية (أسعار، أخبار،
إعلانات باينانس، اقتصاد كلي)، مع رسم بياني حقيقي على بوستات التحليل،
وحارس أمان بالكود بيمنع نشر أي نص مش سليم قبل ما يوصل للنشر الفعلي.

## 1) المفاتيح المطلوبة (Secrets في GitHub)

روح لـ **Settings → Secrets and variables → Actions** في الـ repo، وضيف
كل واحد من دول كـ **New repository secret**:

| الاسم | إجباري؟ | من فين |
|---|---|---|
| `SQUARE_OPENAPI_KEY` | ✅ إجباري | تطبيق باينانس → بروفايلك → Creator Center → Square OpenAPI Key |
| `GROQ_API_KEY` | مستحسن (مجاني) | console.groq.com |
| `GEMINI_API_KEY` | مستحسن (مجاني) | aistudio.google.com |
| `CEREBRAS_API_KEY` | اختياري (مجاني) | cloud.cerebras.ai |
| `OPENROUTER_API_KEY` | اختياري (مجاني) | openrouter.ai |
| `GH_MODELS_TOKEN` | اختياري (مجاني) | GitHub → Developer settings → Fine-grained tokens (صلاحية Account → Models: Read-only) |
| `ANTHROPIC_API_KEY` | اختياري (مدفوع، رخيص جدًا) | console.anthropic.com |

**مفتاح واحد بس إجباري (`SQUARE_OPENAPI_KEY`)** — البوت هيشتغل بأي مجموعة
من الباقي (حتى من غيرهم كلهم، وقتها هيستخدم قوالب نصية جاهزة)، وكل ما
زودت مفاتيح كل ما جودة الكتابة والتنوع اتحسنت.

## 2) التشغيل التلقائي (GitHub Actions + cron-job.org)

جدولة GitHub Actions الداخلية غير موثوقة (best-effort وممكن تتخطى
تشغيلات)، فبنستخدم **cron-job.org** (مجاني) كمشغّل خارجي دقيق يبعت إشارة
`workflow_dispatch` كل ساعة. التفاصيل الكاملة لإعداده اتفقنا عليها سابقًا
معًا (GitHub Token بصلاحية Actions فقط + Cronjob بـ POST على GitHub API).

### تشغيل يدوي/تجريبي
من تبويب **Actions** في الـ repo → اختار الـ workflow → **Run workflow**.

## 3) فئات المحتوى

| الفئة | المصدر |
|---|---|
| أخبار باينانس (إدراج/شطب) | فيد داخلي غير رسمي (Best-effort) |
| أخبار كريبتو عامة | CryptoCompare + Cointelegraph + Decrypt + The Block |
| أخبار اقتصاد كلي (Fed/CPI/NFP...) | MarketWatch RSS |
| تحليل سعر/فني/تمويل أو أعلى رابحين وخاسرين | Binance API الرسمي (مع رسم بياني لتحليل عملة واحدة) |
| تعليم (مصطلحات تداول) | قاموس ثابت |
| سخرية/ميمز | AI |
| شرح أحداث باينانس (Launchpool، Alpha...) | قاموس ثابت |

النسب الحالية: أخبار باينانس 20% / أخبار عامة 14% / اقتصاد كلي 15% /
تحليل 17% / تعليم 13% / سخرية 13% / أحداث 8%.

## 4) خط إنتاج الكتابة (5 محطات AI)

**المحلل (Cerebras)** يلخّص البيانات → **الاستراتيجي (Groq)** يختار
الزاوية → **الناقد (Gemini)** يراجع وينتقد → **الكاتب (OpenRouter)** يكتب
المسودة النهائية (خطاف ≤10 كلمات، رقم حقيقي، رأي، سؤال بخيارين) →
**المدقق (GitHub Models)** مراجعة أخيرة. كل محطة بتتخطى نفسها لو مفتاحها
مش موجود أو فشلت. لو خط الإنتاج كله فشل: Fallback لـ Groq بس، بعدين
Anthropic (لو مفتاحه موجود)، وفي الآخر قوالب نصية ثابتة.

### 🛡️ حارس الأمان (مهم)
كل نص جاي من أي مصدر AI بيتفحص قبل النشر (`validate_post_text`) —
لو فيه علامات نص "تفكير داخلي" مسرّب، أو رسالة فحص أمان بدل الرد الطبيعي،
أو أي حاجة مش شكلها بوست حقيقي، **بيترفض تلقائيًا ويتجرب مصدر تاني** بدل
ما ينشر. ده اتضاف بعد ما حصلت مشكلة فعلية (بوستات نُشرت وفيها نص تفكير
الموديل بالغلط).

## 5) الصور

بوستات "تحليل عملة واحدة" بترفق رسم بياني حقيقي (24 ساعة)، بيتنشر عن طريق
سكريبت باينانس الرسمي (Node.js) اللي بيتحمّل تلقائيًا وقت التشغيل من
مصدره الرسمي على GitHub.

## 6) بديل: سيرفر/VPS خاص بك

```bash
pip install -r requirements.txt
export SQUARE_OPENAPI_KEY="your_key_here"
python square_bot.py
```

وضيفه على cron يشتغل كل ساعة (بعد ما تصدّر كل مفاتيح الـ AI اللي عايز
تستخدمها كمان):

```
0 * * * * cd /path/to/square_bot && python3 square_bot.py >> bot.log 2>&1
```

## 7) ملاحظات وحدود مهمة

- **الحد الأقصى الرسمي للنشر: 100 بوست/يوم** — البوت بينشر مرة كل ساعة
  (~24 يوميًا)، فمريح جدًا تحت الحد.
- **مفيش دعم رسمي للرد على التعليقات أو اللايك التلقائي** — ده لازم يفضل
  يدوي منك، مفيش API رسمي ليه.
- بعض المصادر (فيد إعلانات باينانس، MarketWatch RSS، سكريبت الصور) مش
  موثقة رسميًا وممكن تتغيّر أو تتعطل بدون سابق إنذار — البوت بيتعامل معاها
  كـ Best-effort ودايمًا فيه Fallback يمنعه من التوقف الكامل.
- **الربح (Write to Earn):** برنامج منفصل من باينانس، محتاج تسجيل خاص من
  Creator Center + توثيق هوية الحساب (KYC) — مش حاجة بيضبطها الكود.
  الكود بيساعد بس عن طريق استخدام Cashtags صح ($BTC) عشان يحسّن فرصة
  اكتشاف المحتوى للربط بصفقات القراء.

## 8) فرص تطوير مستقبلية (لسه مأجّلة)
- ذاكرة بين التشغيلات (`state.json`) لتتبع أداء كل فئة وتعديل النسب تلقائيًا

- دعم منصات نشر إضافية غير Square
